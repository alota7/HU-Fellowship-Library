Use:

CREATE TABLE borrowing_requests (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    book_id INT NOT NULL,
    requester_name VARCHAR(100) NOT NULL,
    phone_number VARCHAR(30) NOT NULL,
    school_year VARCHAR(30) NOT NULL,

);

CREATE TABLE borrowings (

    return_requested_at TIMESTAMP NULL,

52. BOOK AVAILABILITY

When a member requests a hardcopy book, reserve one available copy immediately.

Use a transaction.

Example:

UPDATE books
SET available_quantity = available_quantity - 1
WHERE id = ?
  AND book_type = 'hardcopy'
  AND available_quantity > 0;

Only insert the pending request if the update succeeds.

If request insertion fails, roll back.

When rejected:

available_quantity + 1

When returned:

available_quantity + 1

Do not decrement twice during approval if the copy was already reserved during request creation.
