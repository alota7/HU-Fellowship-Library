==================================================
1. PROJECT PURPOSE
==================================================

HU Fellowship Library is a digital library for a fellowship/church community.

The system has two roles:

1. Admin
2. Member

Both roles use the SAME LOGIN PAGE.

The difference between them is their role and permissions.

The system must never ask users to select their role during login.

The backend will eventually return the authenticated user's role.
